# Calculator (com.example.p192097)

A small Android calculator app built with Jetpack Compose (Material 3). Package: `com.example.p192097`.

## What's here

- `MainActivity.kt` — entry point, hosts the Compose UI.
- `CalculatorScreen.kt` — the calculator UI and keyboard (`CustomKeyboard`, `CKey`, `KeyboardMode`).
- `Evaluator.kt` — expression tokenizer/evaluator for the calculator logic.
- `ui/theme/` — Compose Material3 theme (`Color.kt`, `Type.kt`, `Theme.kt`).
- `CrashApp.java` / `CrashActivity.java` / `DiagLogger.java` — lightweight debug-time hooks
  originally generated by the "Yima IDE" scaffold. They send diagnostic logs and crash traces
  back to a companion IDE app (`com.yimaide.app`) during development, and are inert no-ops in a
  normal standalone build (there's no `com.yimaide.app` installed to receive the broadcasts).
  Feel free to strip them out if you don't want that scaffolding — the calculator itself has no
  dependency on them beyond `CrashApp` being the declared `<application android:name>`.

## Project structure

This is a standard Android Studio / Gradle project:

```
.
├── build.gradle              # root: plugin versions
├── settings.gradle           # module list
├── gradle.properties
├── gradle/wrapper/gradle-wrapper.properties
└── app/
    ├── build.gradle           # app module config + dependencies
    ├── proguard-rules.pro
    └── src/main/
        ├── AndroidManifest.xml
        ├── java/com/example/p192097/   # Kotlin + Java sources
        └── res/                        # strings, themes, icons, backup rules
```

## Requirements

- Android Studio (Ladybug/Koala or newer) or command-line Gradle
- JDK 17
- Android SDK with `compileSdk 36` / platform 36 installed

## Build

Open the project root in Android Studio and let it sync (it will generate the Gradle wrapper
jar automatically), or from the command line:

```bash
gradle wrapper --gradle-version 8.9   # first time, to create gradlew/gradlew.bat
./gradlew assembleDebug
```

The built debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

## Notes

- `minSdk 26` (Android 8.0), matching the adaptive-icon-only mipmap resources (no legacy PNG
  mipmaps are needed below API 26).
- The app manifest requests only `VIBRATE`, used for haptic feedback on key presses.
- `applicationId` / `namespace` is `com.example.p192097` — rename it in `app/build.gradle` and
  the manifest/package folders if you want to publish this under your own package name.
